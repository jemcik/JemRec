# tools

Scripts that are not part of the app. Each one is either a device experiment
kept because its measurements are cited in `docs/`, or something that produces
an artefact checked into this repository.

| | |
| --- | --- |
| `hooks/pre-push` | Tests and lint before a push. Install with `git config core.hooksPath tools/hooks`. |
| `render_icon.py` | Redraws the launcher mark as `docs/icon.png` for the README and the site, and at 512px as the F-Droid listing's icon under `fastlane/`. |
| `make_demo_faces.py` | Draws the two invented contact portraits the demo list uses. Output goes to the debug source set, so it ships in no release APK. |
| `shoot.py` | Captures `docs/screenshots/` on the phone - every screen in each of the three looks, light and dark, into `docs/screenshots/<look>/` - with the invented calls turned on, and copies the F-Droid set under `fastlane/`, under a fixed table of 21 file names: F-Droid keeps every screenshot name it is ever given (fdroidserver #490), so a name is never dropped, only given a new picture. Looks, themes and screens can be named to shoot only those (`shoot.py deck dark calls`); `--listing` redoes the copies from disk with no phone. The phone's own look and night mode are put back after. |
| `setup_video.py` | Cuts the setup video from a screen recording made on the phone: a 1920x1080 MP4 with the steps and captions beside the phone, rings at the taps, zooms, speed-ups, and blurs over anything personal, plus an `.srt` and `jemrec-setup.jpg`, a 1280x720 still beside them - copy it over `docs/video/setup.jpg` after a re-record, where the site shows it in place of the player. With `--voice` each caption gets a spoken line from Kokoro (an open text-to-speech model run locally from its own venv) and the frame before a tap is held until the line is done; with `--music` a track from `ambient_music.py` plays 21 dB under her, dipping before each line. The edit is the `TIMELINE` in the script, in the recording's own clock; `--sheet` and `--frame` read times and positions off a new take, `--stills` checks the result without encoding. Needs ffmpeg and numpy. Raw footage stays out of git. |
| `ambient_music.py` | Synthesizes original ambient music from sine waves, envelopes and a noise reverb - no samples, no licence - at any length and the same every time for a seed. Three presets; `night`, a distant felt piano over slow pads, is the setup video's. Needs numpy. |
| `build_site.py` | Generates the site GitHub Pages serves - the landing page, how it works, the setup manual and the privacy policy - and `docs/SETUP.md`, which is the same manual rendered as Markdown from the same source. The site wears the app's three looks (the Look button), from the app's own colours and fonts: the fonts and their licences are copied into `docs/fonts/`, and the manual's table of what the header says is read from the app's header files. The charts are drawn from `MEASURES`, each a measurement from `docs/ARCHITECTURE.md`; a new set of screenshots needs a look at `CROPS`, the parts of screens the feature rows show. Standard library only. |
| `pair-now.sh` | Pairs the phone with its own Wireless debugging from a USB shell, for testing setup without tapping through it. |
| `check_16k_pages.py` | Fails when a native library in the APK would make Android run JemRec in 16 KB page-size compat mode. CI runs it on every build. Standard library only. |
| `emulator_checks.py` | Release checks on an emulator: installs the debug build, sets JemRec up from nothing, and places simulated calls through the real app and daemon - the ringing cut, the same with nothing captured until the answer (issue #40), an unanswered call, an incoming call, a stranger skipped by the rules, two calls in quick succession, a caller-ID name, the self-test, and the answering machine: a message taken, a hang-up during the greeting, a caller the rules leave out, a phone call over a messenger call (a stand-in call from `shellserver/probe`, built by the script), a caller in the day after an emergency call, and a call taken over in Ask first; then another app's call through Telecom as Google Meet's are (the debug build's own stand-in) left alone while a phone call rung in over it is recorded on its own; a phone call whose audio mode turns "communication" in the middle (the stand-in call takes it, playing a tone) followed to the mixer and back, saved exactly, and Diagnostics' Copy a report saying each way (before Android 14, kept on the call capture), and the debug build's stand-in app call placed over a phone call being recorded keeping that phone call on the call capture; then a call's waveform kept as it is saved, a recording played from its row going on with the screen off - named only "Call recording" while locked, held back by a ringing call - a deleted recording brought back by Restore all in Recently deleted and then removed by Delete all for good, file and all - and the same in a folder picked through Android's own picker, with one there whose 30 days are up removed by the daily pass - the app started again in each look, and a kept message still a kept message after an uninstall and a reinstall, read back from the file, a USB cable on a simulated port: the app woken from the daemon, a recorder killed meanwhile started again, USB debugging switched off as an Honor's Settings app does and switched back on by the woken app, adbd stopped with Wireless debugging on as an Honor leaves it after a restart and started again by the app's revive, the header's Tap to allow this Wi-Fi on a Wi-Fi Android has not allowed, the recorder brought back by the tap's own revive after Allow, setup's last step refused its grant as an OPPO, OnePlus or realme phone refuses it until Disable system optimization is on (faked by the debug build, issues #61 and #64) and told that switch, with no ADB session told so rather than sent to a switch, then granted for real by Try again and read back, When JemRec is off's two choices end to end (Developer options and Wireless debugging off with the recorder kept; all debugging off, adb with it, and back on), Start without Wi-Fi (adbd's classic port opened on Wi-Fi, the recorder started over it with Wi-Fi off after all debugging off and on, the port closed again once switched off, or left open where the revive came over it; on a Wi-Fi Android has not allowed - on Android 12 its allowance taken back first - no asking again after Cancel), and the daemon's watch for this phone stopping JemRec in the background reading the device's own exit records - with, on Android 15 and later, a Force stop's open read from the app's own start record and not warned of. PASS or FAIL for each. Turns the emulator's ringtone, notification, system, alarm and media sounds down to about half first, never the call's. Refuses to touch anything but an emulator; needs a `google_apis` image. Standard library only. |
| `capture-call.py` | Records from the daemon in raw PCM and measures each channel separately, which is how to tell "audio arrived" from "both sides of the call arrived". |

The Python ones need Pillow (`python3 -m pip install pillow`); the shell ones
need `adb` and a phone attached.
